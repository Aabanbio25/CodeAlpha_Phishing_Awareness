# CodeAlpha - Phishing Awareness Training Module

An interactive web-based phishing awareness training module built with **HTML, CSS, and JavaScript**. Developed as part of the **CodeAlpha Cybersecurity Internship Program**.

## Features
- Explains core phishing concepts and social engineering tactics.
- Highlights key email red flags (spoofed addresses, urgent language, suspicious links).
- Outlines organizational best practices for phishing prevention.
- Features an interactive knowledge check quiz.

## Tech Stack
- HTML5
- CSS3
- JavaScript
